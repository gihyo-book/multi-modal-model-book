# マルチモーダルモデル入門

『[マルチモーダルモデル入門](https://gihyo.jp/book/2026/978-4-297-15836-1)』（技術評論社、2026年）のサポートリポジトリです。

本書では、Transformerの基礎から、視覚・音声・動画・3次元データを扱うモデル、複数のモダリティを統合するオムニモーダルモデルまで解説します。
